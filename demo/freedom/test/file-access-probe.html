File access probe

Does this browser let a page keep a file the person picked? Each step says ok or the error it met. (ontodag, BROWSER.md §14; Freedom #671.)

  1. — pick any small text file; the page reads it.
  2. — adds a line to the file from step 1, asking for write access.
  3. — pick a name; the page writes it.
  4. — writes the file from step 3 again, without a picker.
  5. — pick a folder; the page lists what is in it (read only).
